# مشروع صفحة أسعار بسيطة (Pricing Page Project)

هذا المشروع عبارة عن صفحة ويب بسيطة ومستجيبة (Responsive) مخصصة لعرض خطط الأسعار، تم بناؤها باستخدام لغات الويب الأساسية.

## 🚀 نظرة عامة
تم تصميم هذه الصفحة لتكون واضحة وسهلة الاستخدام، حيث تعرض ثلاث خطط مختلفة (مجانية، احترافية، وللشركات) مع جدول مقارنة تفصيلي للميزات.

## 🛠️ التقنيات المستخدمة
*   **HTML5**: لبناء هيكل الصفحة.
*   **CSS3**: لتنسيق الصفحة وجعلها تبدو بشكل احترافي.
*   **Font Awesome**: لإضافة الأيقونات الجميلة.

## 📁 محتويات المشروع
*   `index.html`: الملف الأساسي الذي يحتوي على هيكل الصفحة.
*   `style.css`: الملف الذي يحتوي على جميع التنسيقات والألوان.

## 💻 كيف تبدأ؟
كل ما عليك فعله هو تحميل الملفات وفتح ملف `index.html` في أي متصفح ويب (مثل Chrome أو Firefox) وستعمل الصفحة مباشرة.
